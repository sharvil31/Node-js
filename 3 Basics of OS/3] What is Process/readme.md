# What is a Process?

A **process** is an instance of a program that is currently being executed.  
In simple terms, **the applications or programs we use on our device are processes**.

Each process is managed by the operating system and operates independently.

## Key Characteristics of a Process

- Has its **own memory space**
- Uses **CPU time**
- Is scheduled and managed by the **Operating System**
- Can run independently of other processes

## Process States

A process goes through multiple states during its lifecycle:

- **Ready**  
  The process is prepared to run and waiting for CPU allocation.

- **Running**  
  The process is currently being executed by the CPU.

- **Waiting (Blocked)**  
  The process is waiting for an event such as I/O input or resource availability.

- **Sleeping**  
  The process is paused for a specific amount of time.

- **Terminated**  
  The process has completed execution or has been stopped.

## Summary

The operating system continuously switches between processes to provide multitasking and efficient resource utilization.
