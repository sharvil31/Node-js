# Duplex, Transform, and PassThrough Streams in Node.js

```js
import fs from "fs";
import { Readable, Writable, Duplex, Transform, PassThrough } from "stream";
```

## Reading and Writing Using Separate Streams

```js
const readStream = fs.createReadStream(
  "E:\\[AO] Heaven s Feel I - Presage Flower [1080p] [Dual].mkv",
  { highWaterMark: 1 * 1024 * 1024 },
);

const writeStream = fs.createWriteStream("streams.mp4", {
  highWaterMark: 1 * 1024 * 1024,
});
```

Here, two separate streams are used:

- `readStream` reads data from the source file.
- `writeStream` writes data to the destination file.

These streams have separate responsibilities—one only reads and the other only writes.

---

# Readable and Writable Streams

Node.js provides the `Readable` and `Writable` classes in the `stream` module.

```js
import { Readable, Writable } from "stream";
```

These classes allow you to create your own custom readable and writable streams by extending them.

Example:

```js
class MyReadable extends Readable {}
class MyWritable extends Writable {}
```

You can override methods such as `_read()` and `_write()` to define how data should be produced or consumed.

---

# Duplex Stream

```js
import { Duplex } from "stream";
```

A **Duplex Stream** is both:

- Readable
- Writable

at the same time.

Unlike using separate `readStream` and `writeStream`, a single Duplex stream can perform both operations.

```
Read  <------ Duplex ------> Write
```

A Duplex stream has **two independent sides**:

- Readable side
- Writable side

The data being written **does not have to be the same** as the data being read.

For example, when working with the **`net` module**, Node.js provides a **Socket**, which is a Duplex stream.

```
Client  <------ Socket ------> Server
```

You can:

- write data to the socket
- receive data from the same socket

at the same time.

This makes Duplex streams ideal for two-way communication.

---

# Transform Stream

```js
import { Transform } from "stream";
```

A **Transform Stream** is a special type of **Duplex Stream**.

It can both:

- receive data
- output data

but the output is **generated from the input**.

Unlike a normal Duplex stream, the readable side depends on what is written to the writable side.

```
Input
   │
   ▼
Transform
   │
   ▼
Modified Output
```

Examples:

- Compressing files (gzip)
- Encrypting data
- Converting text to uppercase
- Parsing CSV to JSON
- Encoding/Decoding Base64

Example:

```
Input:

hello world

Transform:

toUpperCase()

Output:

HELLO WORLD
```

Think of it like:

```
Water  ---> Freeze ---> Ice
```

The output is still the same underlying data, but represented differently after processing.

---

# PassThrough Stream

```js
import { PassThrough } from "stream";
```

A **PassThrough Stream** is the simplest Transform stream.

It performs **no transformation at all**.

Whatever is written is emitted exactly as it is.

```
Input
   │
   ▼
PassThrough
   │
   ▼
Same Output
```

Example:

```
Input:

Hello Node.js

Output:

Hello Node.js
```

Since no modification occurs, it simply passes the data through unchanged.

---

# Relationship Between Streams

```
Readable        Writable
     \            /
      \          /
       \        /
        Duplex
           │
           ▼
      Transform
           │
           ▼
      PassThrough
```

- **Readable** → Only reads data.
- **Writable** → Only writes data.
- **Duplex** → Can read and write independently.
- **Transform** → A Duplex stream where output is generated by transforming the input.
- **PassThrough** → A Transform stream that performs no transformation and outputs the input unchanged.

---

# Key Differences

| Stream Type | Read | Write | Output Depends on Input | Modifies Data                  |
| ----------- | ---- | ----- | ----------------------- | ------------------------------ |
| Readable    | ✅   | ❌    | ❌                      | ❌                             |
| Writable    | ❌   | ✅    | ❌                      | ❌                             |
| Duplex      | ✅   | ✅    | ❌                      | ❌                             |
| Transform   | ✅   | ✅    | ✅                      | ✅ (or may leave it unchanged) |
| PassThrough | ✅   | ✅    | ✅                      | ❌                             |

---

# Important Note

A **PassThrough** stream is **not a separate category alongside Transform**.

The inheritance chain is:

```
Readable
    ▲
Writable
    ▲
Duplex
    ▲
Transform
    ▲
PassThrough
```

So:

- Every **PassThrough** is a **Transform** stream.
- Every **Transform** is a **Duplex** stream.
- But not every **Duplex** stream is a **Transform** stream.
- And not every **Transform** stream is a **PassThrough** stream.
